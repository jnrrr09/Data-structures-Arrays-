Arrays in the Real World

Arrays help programs store related values in an ordered collection and retrieve each value by its position. This project introduces real-world uses of arrays and demonstrates a two-dimensional array through a small pixel-image editor.

1. Introduction to arrays

An array is a data structure that stores a collection of elements under one name. Each element is identified by an index. In many programming languages, including JavaScript and C++, indexing starts at 0.

For example, marks = [75, 82, 68, 90, 77] stores five marks. The value marks[0] is 75 and marks[3] is 90. A loop can visit every element to calculate totals, averages, minimums, or maximums.

Why arrays? They group related values, allow direct access by index, and make repeated processing with loops simpler. Traditional fixed-size arrays are especially suitable when the number of elements is known in advance.

2. Real-world applications of arrays

These examples show the type of data an array can hold and why indexed storage is useful. Real systems may also use databases or other data structures alongside arrays.

3. Chosen application: a pixel-image editor

Objective

Demonstrate how a digital image can be represented as a two-dimensional array and how simple image transformations operate on its elements.

How it uses an array

The editor stores a 16 × 16 grid. Each position grid[y][x] contains a colour represented by three values: red, green, and blue (RGB).

The array has 16 rows and 16 columns, giving 256 pixel positions. The program accesses a pixel with two indexes: the row y and column x. For example, grid[2][5] refers to the pixel in row 2, column 5.

5. How the array operations work

Access by index

grid[y][x] selects one pixel using its row and column. Direct index access is generally constant time for an array.

Nested loops

A loop inside another loop visits each row and each column. This is a natural way to process every pixel in a two-dimensional array.

Transformations

Flipping and rotating rearrange pixel positions. Inverting changes each RGB channel using 255 - channel.

Neighbour processing

Blur examines nearby pixels and averages their RGB values. Boundary checks prevent the algorithm from reading outside the grid.

Example: invert every pixel

for (let y = 0; y < height; y++) {
  for (let x = 0; x < width; x++) {
    grid[y][x] = grid[y][x].map(channel => 255 - channel);
  }
}

This algorithm uses two loops to visit every pixel. Each pixel has three colour channels, and each channel is replaced by its opposite value. For example, a channel value of 0 becomes 255, while 255 becomes 0.

6. Benefits and limitations

Benefits

  • Organizes similar data by position.
  • Allows direct access to a selected element.
  • Works naturally with loops and grid-based calculations.
  • Makes image transformations easy to demonstrate.

Limitations

  • A traditional fixed-size array cannot grow automatically.
  • Inserting or removing elements in the middle may require shifting values.
  • Large images require substantial memory for pixel data.
  • Practical image software may use specialized image buffers and additional structures.

7. Conclusion

Arrays are useful when an application needs to store many related values and access them by position. They appear in image processing, audio, spreadsheets, games, student results, and scientific computing. The pixel-image editor demonstrates a two-dimensional array in practice: each pixel is stored at a row and column, and nested loops perform transformations across the grid.

Project scope: This is an educational demonstration, not a full professional image editor. It uses a 16 × 16 grid and runs locally in a web browser.
